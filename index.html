Импорт данных

CSV (разделитель , ; или Tab) и JSON. Юниты: id,name,hp,attack,defense,cost (+ необязательные crit_chance,crit_mult,attack_speed). Лут: id,item,chance (+ group,rarity). Навыки: JSON {"nodes":[...]}. Файл проекта (кнопка «Экспорт проекта») восстанавливает всё.

Примеры:

Редактор таблицы

Изменения сохраняются автоматически в localStorage.

Калькулятор урона и TTK

урон = max(attack − defense, attack × minRatio) × множитель; ожидаемый = урон × (1 + critChance × (critMult − 1)); удары = ⌈hp / урон⌉; TTK = (удары − 1) / attackSpeed

Матрица ожидаемого TTK (строка атакует столбец), секунды

0 — цель погибает с первого удара. Наведите на ячейку, чтобы увидеть число ударов.

Кривая прогрессии

XP до следующего уровня = round(base × Lpower + linear × (L − 1))

Проверка таблицы лута

Сумма chance внутри каждой группы (group) должна быть ровно 100%. Редактировать строки можно во вкладке «Таблица → Лут».

Аудит баланса

Каждый юнит дерётся с каждым (по ожидаемому TTK). Эффективность = доля побед ÷ (цена ÷ медианная цена). Относительно медианы: ≥ 1.3 — доминирует, ≤ 0.7 — бесполезен. Сила/цена = hp × средний DPS ÷ cost.

Симулятор инфляции

балансt = балансt−1 + Σ источник × (1 + рост)t−1 − Σ сток × (1 + рост)t−1
